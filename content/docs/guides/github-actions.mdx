# GitHub Actions

A complete workflow for running Quell on every pull request and updating a score badge on main.

## One-command setup

```bash
quell install --pr
```

This writes `.github/workflows/quell-pr.yml` to your project — a ready-to-use workflow that posts a Quell report as a PR comment on every PR that changes Python files. No configuration needed.

## Complete workflow

```yaml
# .github/workflows/quell.yml
name: Quell

on:
  pull_request:
    branches: [main]
  push:
    branches: [main]

permissions:
  contents: write

jobs:
  quell:
    name: Requirement Coverage
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-python@v5
        with:
          python-version: "3.11"

      - name: Install dependencies
        run: |
          pip install quelltest
          pip install -e ".[dev]"

      - name: Quell CI
        run: quell check src/ --no-llm --format json
        env:
          QUELL_API_KEY: ${{ secrets.QUELL_API_KEY }}   # optional — from quell auth login

      - name: Update badge (main only)
        if: github.event_name == 'push' && github.ref == 'refs/heads/main'
        run: |
          quell score --badge
          git config user.name  "github-actions[bot]"
          git config user.email "github-actions[bot]@users.noreply.github.com"
          git add .quell/badge.svg
          git diff --staged --quiet || git commit -m "chore: update quell score badge [skip ci]"
          git push
```

## What the workflow does

### On pull requests
1. Checks out the code
2. Installs `quelltest` and your project dependencies
3. Runs `quell ci src/ --threshold 0.75` — fails the build if requirement coverage drops below 75%

### On main push
1. Runs the same check
2. Regenerates the SVG badge and commits it back to `main`

## Required secrets

| Secret | Required | Description |
|--------|----------|-------------|
| `GITHUB_TOKEN` | Yes (automatic) | For git push and PR comments — provided automatically by Actions |
| `QUELL_API_KEY` | No | From `quell auth login`. Required only for authenticated features (usage analytics, Pro plan limits) |

## PR comment workflow

Post a Quell report as a PR comment on every pull request:

```yaml
# generated by: quell install --pr
name: Quell PR Report

on:
  pull_request:
    paths: ["**/*.py"]

permissions:
  pull-requests: write

jobs:
  quell-pr:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.11"
      - run: pip install quelltest
      - name: Run Quell PR check
        run: quell pr ${{ github.event.pull_request.number }} --comment --no-llm
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

## Minimal workflow (no badge)

If you just want the threshold gate:

```yaml
- name: Quell check
  run: |
    pip install quelltest
    quell check src/ --no-llm --format json
```
