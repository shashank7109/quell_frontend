# Installation

## Requirements

- Python **3.11** or higher
- `pytest` (for test verification — installed automatically)

No mutation testing tool required. Quell reads specs, not mutation results.

## Install from PyPI

```bash
pip install quelltest
```

<Callout type="info">
  The PyPI package name is `quelltest`. The CLI command is `quell`.
</Callout>

## Recommended: use a virtual environment

```bash
python -m venv .venv
source .venv/bin/activate      # Linux/macOS
.venv\Scripts\activate         # Windows

pip install quelltest
```

Or with `uv` (faster):

```bash
uv venv
uv pip install quelltest
```

## Optional extras

### MCP server (AI agent integration)

```bash
pip install "quelltest[mcp]"
```

Exposes Quell tools to Claude Code, Cursor, Devin, and any MCP-compatible agent.

### LLM configuration

Anthropic and OpenAI clients are included in the base install. Set your key to enable LLM-powered analysis of complex unstructured specs:

```bash
export ANTHROPIC_API_KEY=sk-ant-...   # for Claude
export OPENAI_API_KEY=sk-...          # for GPT-4
```

### Local LLM (Ollama)

Run without any cloud API key:

```bash
# Install Ollama: https://ollama.ai
ollama pull codellama

# Tell Quell to use Ollama in pyproject.toml:
# llm_provider = "ollama"
```

## Verify installation

```bash
quell --version
# quelltest 0.4.0

quell --help
```

## Updating

```bash
pip install --upgrade quelltest
```

## Windows note

Quell runs natively on Windows. The CLI, verification engine, and AST-based spec readers all work without WSL.
