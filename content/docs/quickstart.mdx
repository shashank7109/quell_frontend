# Quickstart

This guide assumes you have a Python project with docstrings or Pydantic models. If not, the example below creates one from scratch.

## 1. Install Quell

```bash
pip install quelltest
```

## 2. Add a spec to your code

If you don't have one already, add a docstring or a Pydantic model:

```python
# payments.py
from pydantic import BaseModel, Field
from typing import Literal

class PaymentRequest(BaseModel):
    amount: float = Field(gt=0)
    currency: Literal["USD", "EUR", "GBP"]

def process_payment(request: PaymentRequest) -> dict:
    """
    Process a payment transaction.

    Raises:
        ValueError: If amount is zero or negative.
    """
    if request.amount <= 0:
        raise ValueError("Amount must be positive")
    return {"transaction_id": "txn_123", "status": "ok", "amount": request.amount}
```

## 3. Find untested edge cases

```bash
quell find src/
```

Quell reads docstrings and Pydantic models, extracts every edge case, and shows three buckets:


## 4. Write the tests

Add `--fix` to write WRITTEN tests to disk:

```bash
quell find src/ --fix
```

Add `--auto` to skip the confirmation prompt (use in CI):

```bash
quell find src/ --fix --auto
```

## 5. Complete a scaffold stub

Open the stub in `tests/scaffold/test_payments.py`, fill in the assertion, and move it to your main test suite:

```python
# Before (generated stub)
def test_quell_scaffold_process_payment_req_abc123():
    from payments import process_payment
    # quell: complete assertion
    # TODO: call process_payment() and assert the edge case behaviour
    pass

# After (your assertion)
def test_process_payment_rejects_zero_amount():
    with pytest.raises(ValueError):
        process_payment(PaymentRequest(amount=0, currency="USD"))
```

```bash
quell score
```

## 7. Set up CI

Install the GitHub Action in one command:

```bash
quell install --action
```

This writes `.github/workflows/quelltest.yml`. On every PR it runs `quell find --format github`, posts inline annotations on untested lines, and comments a PRS summary.

## 8. Optional — LLM fallback for harder cases

About 75% of edge cases are handled with no network calls. For the rest, enable Groq (fast, free tier):

```bash
quell auth set --provider groq --key gsk-...
quell find src/ --fix --use-llm
```
