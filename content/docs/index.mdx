# Quell Documentation — v2.0.0

**Untested edge cases will bite you in production. Quell finds them before they do.**

Quell scans your docstrings, Pydantic models, and PySpark schemas, extracts every testable edge case, runs each candidate through a 5-gate pipeline, and sorts results into three buckets: **WRITTEN** (verified tests on disk), **SCAFFOLDED** (stubs for you to complete), **FLAGGED** (explained gaps). Every test that Quell writes has passed 5 gates.

<Callout type="tip">
  **New here?** Jump to the [Quickstart](/docs/quickstart) to scan your first project in under 5 minutes.
</Callout>

## The problem Quell solves

Other test generation tools read your implementation and generate tests for what your code *does*. If your code has a bug, they generate tests that bless it.

Quell reads your **specification** — the docstring that says "must raise ValueError", the Pydantic model that says `Field(gt=0)` — and generates a test that proves the requirement is enforced. It catches bugs instead of blessing them.

## How it works

<Steps>
  <Step title="Find edge cases">
    `quell find src/` scans docstrings, Pydantic models, PySpark schemas, and guard clauses. Each edge case becomes a typed Requirement.
  </Step>
  <Step title="Check coverage">
    An AST-based coverage checker scans your test files and marks each Requirement as covered or uncovered — no test execution required.
  </Step>
  <Step title="Generate and gate">
    For each gap, the rule engine generates a candidate test. It passes through 5 gates: AST valid, original, safe, passes on correct code, fails on violated code.
  </Step>
  <Step title="Route to bucket">
    Gate 1–5 survivors are WRITTEN to disk. Earlier failures become SCAFFOLDED stubs. Requirements that can't be synthesized at all are FLAGGED with a reason.
  </Step>
</Steps>

## Quick start

```bash
pip install quelltest
quell find src/               # see three-bucket output
quell find src/ --fix         # write WRITTEN tests
quell install --action        # set up GitHub Actions
```

## Supported spec sources

| Source | Examples extracted |
|--------|-------------------|
| Docstrings | `Raises: ValueError if amount <= 0`, `Returns: dict with status` |
| Pydantic models | `Field(gt=0)`, `Field(min_length=1)`, `Literal["USD", "EUR", "GBP"]` |
| Type annotations | `Literal["active", "inactive"]` function arguments |
| Bug descriptions | `"payment accepts zero amount silently"` |
| PySpark schemas | `StructType([StructField("amount", DoubleType(), nullable=False)])` |

Requires Python 3.11+. The CLI command is `quell`. See [Installation](/docs/installation) for virtual environment setup.
