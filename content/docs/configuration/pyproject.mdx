# pyproject.toml Configuration

Quell reads configuration from the `[tool.quell]` section of your `pyproject.toml`. Run `quell init` to generate a starter config.

## Initialize

```bash
quell init
```

Adds to your `pyproject.toml`:

```toml
[tool.quell]
llm_provider = "anthropic"
llm_model = "claude-sonnet-4-5"
max_verification_attempts = 3
verification_timeout_seconds = 30
auto_write = false
```

## Full reference

```toml
[tool.quell]
# LLM settings
llm_provider = "anthropic"           # "anthropic" | "openai" | "ollama"
llm_model = "claude-sonnet-4-6"      # model name for the provider
ollama_base_url = "http://localhost:11434"

# Verification
max_verification_attempts = 3         # retry count for flaky tests
verification_timeout_seconds = 30     # subprocess timeout per test run

# Writing behaviour
auto_write = false                    # skip confirmation prompt if true
test_file_pattern = "tests/test_{source_file}.py"

# Exclusions
exclude_operators = []               # e.g. ["UNKNOWN", "STRING_MUTATION"]

# Paths
audit_log_path = ".quell/audit.jsonl"
backup_dir = ".quell/backups"
```

## Option descriptions

### `llm_provider`

Which LLM to use for `UNKNOWN` operators. Quell never calls the LLM for operators it handles with rule-based generation.

| Value | Requires |
|-------|---------|
| `"anthropic"` | `ANTHROPIC_API_KEY` env var |
| `"openai"` | `OPENAI_API_KEY` env var |
| `"ollama"` | Ollama running locally |

### `llm_model`

Model name passed to the provider. Defaults:

| Provider | Default model |
|----------|---------------|
| `anthropic` | `claude-sonnet-4-6` |
| `openai` | `gpt-4o` |
| `ollama` | `llama3` |

### `max_verification_attempts`

How many times to retry verification if the test result is non-deterministic. Use `1` for strict mode, `3` for tolerating flaky infrastructure.

### `verification_timeout_seconds`

Maximum time (in seconds) for a single pytest subprocess run. If your test suite has heavy fixtures, increase this.

### `auto_write`

If `true`, Quell writes verified tests without asking for confirmation. Same as passing `--auto` to `quell fix`. Useful for automated scripts.

### `test_file_pattern`

Template for where to write tests for a given source file.

```toml
# Default: tests/test_payments.py for src/payments.py
test_file_pattern = "tests/test_{source_file}.py"

# For src/ layout
test_file_pattern = "tests/unit/test_{source_file}.py"

# Flat layout
test_file_pattern = "test_{source_file}.py"
```

### `exclude_operators`

Skip specific mutation operators entirely.

```toml
exclude_operators = ["UNKNOWN", "STRING_MUTATION"]
```

Useful if you don't have an LLM configured and don't want to see `UNKNOWN` in every report.

## Monorepo setup

For projects with multiple packages, each sub-package can have its own `pyproject.toml`:

```
my-monorepo/
├── packages/
│   ├── payments/
│   │   ├── pyproject.toml   # [tool.quell] here
│   │   └── src/
│   └── auth/
│       ├── pyproject.toml   # [tool.quell] here
│       └── src/
```

Run with:

```bash
quell ci --root packages/payments
quell ci --root packages/auth
```
