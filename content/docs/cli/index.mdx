# CLI Reference

Quell provides a single entry-point command `quell` with several subcommands.

## Global options

All commands accept these options:

| Option | Default | Description |
|--------|---------|-------------|
| `--root` | `.` | Project root directory |
| `--help` | — | Show help and exit |

## Commands

| Command | Description |
|---------|-------------|
| [`quell check`](/docs/cli/check) | Scan specs, find requirement gaps, optionally generate verified tests |
| [`quell reproduce`](/docs/cli/reproduce) | Convert a bug description into a verified failing test |
| [`quell prove`](/docs/cli/prove) | Show requirement coverage score for a file or function |
| [`quell score`](/docs/cli/score) | Show project-wide Quell Score and optional SVG badge |
| [`quell ci`](/docs/cli/ci) | CI mode: check requirements and exit 1 if below threshold |
| [`quell init`](/docs/cli/init) | Add `[tool.quell]` to `pyproject.toml` |

## Getting help

```bash
quell --help
quell check --help
quell ci --help
```

## Shell completion

```bash
# bash
quell --install-completion bash

# zsh
quell --install-completion zsh

# fish
quell --install-completion fish
```
