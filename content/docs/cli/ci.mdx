# quell ci

Designed for continuous integration pipelines. Runs mutation testing, auto-fixes survivors, enforces a score threshold, and outputs results in console, JSON, or GitHub Actions format.

## Usage

```bash
quell ci [OPTIONS]
```

## Options

| Option | Default | Description |
|--------|---------|-------------|
| `--threshold`, `-t` | `0.0` | Fail CI if score is below this (0.0–1.0) |
| `--diff-only` | `False` | Only mutate lines changed in this PR |
| `--base` | `origin/main` | Base ref for diff comparison |
| `--report` | `console` | Output format: `console`, `json`, `github` |
| `--dry-run` | `False` | Generate and verify but don't write files |
| `--root`, `-r` | `.` | Project root directory |
| `--tool`, `-t` | `mutmut` | Mutation tool: `mutmut` or `stryker` |

## Examples

```bash
# Basic CI run
quell ci

# Fail if mutation score drops below 80%
quell ci --threshold 0.8

# Only test changed lines (fast mode for PRs)
quell ci --diff-only

# Output JSON for dashboards
quell ci --report json

# Full GitHub Actions integration
quell ci --diff-only --threshold 0.75 --report github
```

## The `--diff-only` flag

This is the most important flag for CI performance. Instead of running `mutmut` on the entire project (15–30 minutes), it:

1. Runs `git diff --unified=0 origin/main...HEAD` to find changed Python files and lines
2. Runs `mutmut run <module>` only for changed files
3. Filters results to only include mutants on changed lines

**Result:** 2–3 minutes instead of 15–30 minutes on a typical PR.

<Callout type="tip">
  Use `--diff-only` in your PR CI workflow and full `quell ci` (no flag) in a nightly job.
</Callout>

## Threshold enforcement

The threshold is a float from `0.0` to `1.0` representing the minimum acceptable mutation score.

```bash
quell ci --threshold 0.8   # fail if score < 80%
```

- Exit code `0`: score ≥ threshold (CI passes)
- Exit code `1`: score < threshold (CI fails)

## Report formats

### Console (default)

Human-readable Rich output with tables and color.

### JSON

```bash
quell ci --report json
```

Writes `.quell/ci-report.json`:

```json
{
  "score_before": 0.71,
  "score_after": 0.93,
  "fixed_count": 12,
  "skipped_count": 1,
  "total_survivors": 14,
  "threshold_result": {
    "passed": true,
    "score": 0.93,
    "threshold": 0.8,
    "message": "Score 93% ≥ threshold 80%"
  },
  "dry_run": false
}
```

### GitHub Actions

```bash
quell ci --report github
```

Emits `::set-output` and `::notice`/`::error` annotations that appear inline in the PR diff view.

## Exit codes

| Code | Meaning |
|------|---------|
| `0` | Success (and score ≥ threshold if set) |
| `1` | Score below threshold |
| `2` | No mutation cache found |
| `3` | Unexpected error |
